## Decisions and conventions

- Tomato is for primary buttons and hearts only. Ink 2px borders + solid offset shadows. Text always on solid cards, never directly on patterns.
- UI line icons come from `lucide-react`; colourful doodles from the kit. No emoji in interface chrome. Keep the warm Taglish-friendly copy.
- Old-brand hex values and the legacy alias block are removed page by page; R8 verifies none remain.
- html2canvas (Calendar Dump export) cannot draw `color-mix` or backdrop blur: keep them out of exported sheets.
- Hand-written helpers for scripts: write files with the Write tool; large bash heredocs containing apostrophes break the shell tool.
